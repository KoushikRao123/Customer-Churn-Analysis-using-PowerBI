# Customer-Churn-Analysis-using-PowerBI
"Hyderabad's real estate market is booming—especially around IT hubs like Gachibowli, Madhapur, and Kondapur—but pricing varies wildly from one street to the next. Before building any visuals, I engineered a clean 18-column schema in Power Query—extracting exact latitudes, longitudes, RERA status,  standardizing all prices into numeric INR values."
